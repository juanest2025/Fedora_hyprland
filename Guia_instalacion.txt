====================================================
GUÍA COMPLETA DE INSTALACIÓN Y SETUP DE HYPRLAND (WAYLAND)
====================================================

Sistema objetivo:
- Fedora Linux
- Window Manager: Hyprland
====================================================

PASOS PREVIOS:
====================================================

1. ACTUALIZAR SISTEMA
sudo dnf update -y
sudo reboot

2. ACTIVAR COPR (repo con Hyprland actualizado)
sudo dnf copr enable solopasha/hyprland -y

3. INSTALAR HYPRLAND
sudo dnf install hyprland -y

4. INSTALAR DEPENDENCIAS
sudo dnf install -y waybar mako hyprpaper wl-clipboard brightnessctl playerctl gammastep wofi kitty grim slurp swaylock wlogout NetworkManager-gtk nm-applet pipewire pipewire-pulse bluez gammastep libnotify

Extras:
sudo dnf install -y hyprland-qtutils brave-browser vlc ranger

5. CREAR CARPETAS
mkdir -p ~/.config/hypr
mkdir -p ~/.config/waybar
mkdir -p ~/.config/mako
mkdir -p ~/.config/hyprpaper
mkdir -p ~/.config/wofi
mkdir -p ~/Pictures

6. CONFIGURAR HYPRLAND
nano ~/.config/hypr/hyprland.conf

7. CONFIGURAR FONDO DE PANTALLA
nano ~/.config/hyprpaper/hyprpaper.conf

Ejemplo de hyprpaper.conf:
preload = ~/Pictures/wallpaper.jpg
wallpaper = ,~/Pictures/wallpaper.jpg

8. ACTIVAR AUDIO
systemctl --user enable --now pipewire pipewire-pulse

9. INICIAR HYPRLAND
Seleccionar Hyprland en la pantalla de login
O ejecutar: Hyprland (desde TTY)

ATAJOS IMPORTANTES:
====================================================
SUPER + Enter     = Terminal (Kitty)
ALT + Space       = Wofi (Launcher)
SUPER + Q         = Cerrar ventana
SUPER + Shift + R = Recargar config
SUPER + Shift + E = Wlogout (menú apagado)
Ctrl + Shift + L  = Bloquear pantalla (swaylock)
SUPER + F         = Pantalla completa
SUPER + P         = Menú de screenshots (grim + slurp)
SUPER + V         = Portapapeles (wofi cliphist)

ATAJOS DE VOLUMEN Y BRILLO:
====================================================
SUPER + F11       = Bajar brillo
SUPER + F12       = Subir brillo
SUPER + F9        = Bajar volumen
SUPER + F10       = Subir volumen

CAMBIAR VENTANAS:
====================================================
SUPER + Arrow     = Moverse entre ventanas
SUPER + Tab       = Cambiar ventana reciente
SUPER + 1-9       = Workspace 1-9
SUPER + Shift + 1-9 = Mover ventana a workspace

MOVIMIENTOS Y TAMAÑO:
====================================================
SUPER + H/J/K/L   = Mover cursor
SUPER + Arrow     = Mover ventana
SUPER + Ctrl + Arrow = Redimensionar ventana

ANIMACIONES:
====================================================
Rápidas:
animations {
    enabled = true
    animation = windows,1,1,default
    animation = fade,1,1,default
    animation = workspaces,1,1,default
}

Instantáneo (desactivar animaciones):
animations {
    enabled = false
}

EXTRAS RECOMENDADOS:
====================================================

Notificaciones: mako
Gestor archivos: ranger
    - a = renombrar
    - s = shell vim
    - d = delete
    - cw = renombrar rápido

Montaje USB: udiskie
Clipboard: cliphist
Bluetooth: blueman

REPRODUCTOR DE MÚSICA CMUS:
====================================================
sudo dnf install cmus -y

Comandos:
:add ~/Music           = Agregar música
:clear && :add ~/Music = Actualizar lista
+ / -                  = Subir/bajar volumen
ENTER                  = Reproducir
C                      = Siguiente
B                      = Anterior
X                      = Reiniciar
V                      = Pausar
/                      = Buscar

SCREENSHOTS:
====================================================
sudo dnf install grim slurp wl-clipboard -y

Pantalla completa (guardar):
grim ~/Pictures/screenshot.png

Selección con mouse:
grim -g "$(slurp)" ~/Pictures/screenshot.png

Al portapapeles:
grim -g "$(slurp)" - | wl-copy

Atajo recomendado (agregar en hyprland.conf):
bind = , Print, exec, grim -g "$(slurp)" - | wl-copy

DESCOMPRIMIR .RAR:
====================================================
sudo dnf install rar unrar -y

rar a archivos.rar *
unrar x archivo.rar

SOLUCIÓN ERRORES:
====================================================

Waybar no responde:
pkill waybar && waybar &

WiFi no conecta:
sudo systemctl enable --now NetworkManager

Pantalla negra (config corrupta):
rm ~/.config/hypr/hyprland.conf
cp /usr/share/hyprland/hyprland.conf ~/.config/hypr/

Logs de Hyprland:
journalctl -f -u Hyprland
